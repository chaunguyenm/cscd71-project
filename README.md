# Parallelizing Short-time Fourier Transforms 

An implentation and analysis of parallelization of several approaches to calculating short-time Fourier transforms.

## Description

This project studies the implementation of short-time Fourier transforms, commonly used in audio/signal processing. Several approaches are provided, including a quasi-parallel implementation proposed by Alfonso B. Labao et al. An analysis on parallelizing these implementations using OpenMP, MPI, and a hybrid of both paradigms is then conducted on [the Teach cluster](https://docs.scinet.utoronto.ca/index.php/Teach) and presented in the enclosed report.
